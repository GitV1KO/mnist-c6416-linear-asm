# 测试图片在哪里

本目录的 20 张 PNG 是从 `../data/data.txt` 前 20 张样本还原的，和 `../conv/cnn_data.h` 默认编译进 DSP 的 20 张图对应。原数据总共有 10,000 张；每张是 28×28 个像素，每个像素在文本里占一行，共 784 行。

- `sample_00000_label_7.png`：第 0 张图，真实数字为 7，原尺寸 28×28。
- `preview.png`：前 20 张的放大预览，标题格式为“样本编号:真实数字”。标题不是 CNN 的预测结果。
- `index.csv`：图片编号、真实标签、文件名的对应关系。

文本中 0 是黑色背景，1 是白色笔迹。PNG 为方便显示，将它们映射到亮度 0 和 255；送入当前 CNN 时应使用 0/1，不能直接送入 0/255。

`data/label.txt` 保存真实答案，只用于检查预测准确率。CNN 根据图像和训练好的权重做预测，不读取这个真实答案。

重新导出（项目根目录，标准 Python 3，无额外依赖）：

```sh
python3 tools/export_test_images.py --count 20 --offset 0
```

自己的 PNG/JPG 需要先在电脑端进行单数字裁剪、适当留边与居中、缩放为 28×28、统一为黑底白字、二值化为 0/1，再将 784 个按行排列的数值导出成 C 数组。DSP 随后调用 `cnn_forward()` 输出类别 0～9。

当前主程序使用已编译的像素数组，尚未提供直接选择或解码 PNG/JPG 文件的入口。这些 PNG 是为了让测试数据可以直观看到，并不是主程序运行时重新打开的图片文件。
